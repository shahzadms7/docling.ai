# Accessibility Standard

Accessibility is a release requirement, not cosmetic polish.

Required baseline:
- keyboard-operable navigation and controls;
- visible focus indicators;
- semantic HTML landmarks/headings;
- labels for controls and icon-only actions;
- no color-only meaning;
- sufficient text/background contrast across White, Black, Microsoft and Google themes;
- browser zoom and responsive layouts;
- reduced-motion support;
- status text alongside icons/colors;
- accessible tables, forms, dialogs and validation messages;
- screen-reader-readable progress and error states.

Pilot and Enterprise promotion require an accessibility review and recorded exceptions.
