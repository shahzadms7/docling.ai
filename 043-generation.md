# Document Generation Standard

Supported target families: DOCX, XLSX, PPTX, PDF, Markdown, text, code and diagrams.

Generated artifacts must include:
- artifact_id and timestamp
- source/evidence manifest
- model/tool versions where AI was involved
- DRAFT/HUMAN_REVIEW/APPROVED lifecycle
- reproducibility inputs where practical
- validation result
- clear distinction among SOURCE CLAIM, HUMAN CORRECTION, PUBLIC RESEARCH, AI INTERPRETATION and APPROVED DECISION

Generation never overwrites SOURCE. Published/approved outputs are immutable versions; later edits create new versions.
