# Theme Standard

The Command Center supports four local visual themes:

1. **White** — neutral enterprise light theme.
2. **Black** — high-contrast dark enterprise theme.
3. **Microsoft** — Microsoft-inspired Fluent-style color tokens using blue, green, yellow and red semantics.
4. **Google** — Google-inspired Material-style blue, green, yellow and red semantics.

These are independent design presets; they do not imply affiliation, certification or endorsement by Microsoft or Google.

## Standardization rules
- One semantic token system powers all themes.
- Status meaning does not change between themes.
- PASS/success, WARN, FAIL/danger and INFO retain accessible text labels; color is never the only signal.
- No CDN, remote font or remote design asset.
- Theme selection persists locally in browser storage.
- Default is White.
- High-contrast focus rings remain visible.
- Responsive behavior and reduced-motion support are mandatory.
