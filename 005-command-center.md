# Command Center Contract
Default localhost workspace:
Add Documents | Queue | Processing | Exceptions | Library | Hybrid Search | AI Chat | Deep Analysis | Code | Research | Architecture | Create Documents | Review | Outputs | Sessions | Audit | Health | Backup/Recovery | Models/Settings.

## Add Documents
User selects local files. Engine stages a copy, records event/run/session IDs, checks stability, hashes, detects type, inventories safety-relevant structures, and atomically admits to the configured SOURCE lane. Original selected file is never edited. Every discovered file receives an explicit accountable state.

## Chat
Retrieval-first local AI. Answers cite document and best available structural coordinate (page/sheet/slide/section/paragraph/line/chunk). Corpus text is untrusted evidence, never executable instruction.

## Create
Governed generation targets DOCX, XLSX, PPTX, PDF, Markdown, text, code and diagrams. Outputs carry source manifests and DRAFT/HUMAN_REVIEW/APPROVED lifecycle.
