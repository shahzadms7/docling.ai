# Quality Gates

## Gate 0 — Package Integrity
Naming, manifest, hashes, no duplicate sequence numbers, required entry points.

## Gate 1 — Environment Qualification
Supported OS/runtime, fixed local disk, permissions, disk headroom, dependency states.

## Gate 2 — Deterministic Foundation
SOURCE immutability, explicit states, run ledger, event logs, failure handling.

## Gate 3 — Parser Certification
Synthetic DOCX/XLSX/PPTX/PDF/image/code fixtures pass positive and failure cases.

## Gate 4 — Corpus Reconciliation
No unexplained discovered/accounted/indexed mismatches.

## Gate 5 — Retrieval Certification
Exact, FTS and semantic/hybrid test queries meet acceptance criteria.

## Gate 6 — AI Grounding
Citations resolve; unsupported assertions are identified; prompt injection tests pass.

## Gate 7 — Generation Certification
Generated files open, contain required structures/manifests and pass human-review workflow.

## Gate 8 — Recovery
Crash/restart, backup/restore, index rebuild, migration rollback tested.

## Gate 9 — Pilot Readiness
Monitoring, runbooks, capacity baseline, security regression, operator training.

## Gate 10 — Enterprise Readiness
Organization-specific security, supply chain, DR objectives, change governance, accessibility, release certification.

No later gate can waive an earlier failed gate.
