# Testing and Certification Strategy

Certification layers:
1. static package integrity
2. environment qualification
3. synthetic fixture ingestion
4. parser structural validation
5. reconciliation/accounting
6. duplicate/rename/delete lifecycle
7. failure/retry/recovery
8. search correctness
9. embedding/hybrid retrieval
10. citation grounding
11. AI safety/prompt-injection tests
12. document-generation validation
13. Command Center localhost/UI tests
14. backup/restore drill
15. upgrade/migration regression
16. performance/capacity baseline

A release is certified only against a named edition/profile and evidence bundle. Version number alone does not mean certified.
