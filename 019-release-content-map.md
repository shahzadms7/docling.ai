# Release Content Map

The downloadable package and public repository must carry the same payload files for a release. The ZIP archive itself is the distribution artifact and is not embedded recursively inside itself.

## Operator journey
README -> 001 -> 002-019 -> 020 orchestrator -> generated deployment plan -> implementation/checkpoints -> certification -> Command Center.

## Fixture journey
100-105 synthetic inputs -> 110-115 expected extraction references -> 120-121 visual/report references -> 150+ generated-output examples.

## Engineering journey
200 extraction/corpus -> 300 retrieval -> 400 AI/agent -> 500 Command Center -> 600 generation -> 700 tests -> 800 operations -> 900 release evidence.

Every new file must fit one range and be added to the release manifest.
