# Deployment Tiers
| Capability | Prototype | MVP | Pilot | Enterprise |
|---|---|---|---|---|
| Synthetic certification | Required | Required | Required | Required |
| Real corpus | No | Controlled | Controlled | Governed |
| Keyword/FTS | Demo | Yes | Yes | Yes |
| Embeddings/hybrid | Demo | Yes | Yes | Yes |
| Ollama chat | Demo | Yes | Yes | Governed |
| Command Center | Preview | Operational | Monitored | Hardened |
| Backup/restore test | Basic | Required | Required | Certified |
| Audit/trace | Basic | Full | Full | Full + governance |
| Change/migration gates | Basic | Required | Required | Certified |

Promotion is evidence-based. A higher tier never weakens SOURCE immutability, identity, audit, recovery, or validation contracts.
