# Command Center UX Standard

## Design principles
Calm, dense, legible enterprise workspace. Progressive disclosure. Keyboard-friendly. Accessible contrast. Responsive layout. No remote assets. No decorative animation that slows operations.

## Information architecture
Home | Add Documents | Queue | Processing | Exceptions | Library | Search | AI Chat | Deep Analysis | Code | Research | Architecture | Create | Review | Outputs | Sessions | Audit | Health | Backup/Recovery | Models/Settings.

## Status language
PASS = verified. WARN = usable with known issue. STOP = unsafe/unmet prerequisite. FAIL = test/operation failed. PENDING_REVIEW = human decision needed.

## Palette
Use local CSS design tokens only. Primary enterprise blue plus semantic green/yellow/red; optionally expose Microsoft-style and Google-style palette presets without claiming affiliation.

## Accessibility
Visible focus states, semantic landmarks, ARIA labels for icon buttons, text alternatives, reduced-motion preference, no color-only status encoding, minimum readable type and scalable zoom.
