# Auto Discovery / Debug / Heal Contract
State machine: DISCOVER → ASSESS → PLAN → APPROVE → IMPLEMENT → VERIFY → TEST → REPAIR → RETEST → CERTIFY → OPERATE → MONITOR.

Safe automatic repair: recreate managed folders, validated stale-temp cleanup, bounded transient retry, rebuild disposable indexes, idempotent resume.
Approval required: dependency/model upgrades, schema migration, restore, mass reprocessing.
Never automatic: modify/delete SOURCE, disable security, bypass policy, execute macros, upload corpus, hide failures, guess corrupted evidence.
